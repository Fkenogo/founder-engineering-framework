## 1. Set Boundary and Candidate Assessment

This set converts the eight preparation themes in
[FEF-FGR-002-D2-MOB-001](FEF-FGR-002-D2-MOB-001-EVIDENCE-GOVERNANCE-MOBILISATION-RECORD.md)
into the smallest bounded set found to provide complete D2 coverage. It contains
no answers, evidence conclusions, Governance Findings, Founder Decision options,
constitutional wording, or engineering requirements.

| Quality Test | Outcome | Treatment |
|---|---|---|
| Coverage | Pass | Every approved D2 subject maps to at least one RQ |
| Neutrality | Pass | No preferred hierarchy, threshold, disposition, or control is assumed |
| Duplication | Pass | Shared subjects use dependencies rather than repeated questions |
| Scope integrity | Pass | D3–D8 matters are interfaces or exclusions only |
| Question independence | Pass | Each RQ has one coherent analysis purpose |
| Dependency order | Pass | Identity precedes weighting and admission; these precede sufficiency and pack control |
| Evidence feasibility | Pass | Candidate source classes exist without relying on an answer |
| Open Question mapping | Pass | OQ-005, OQ-006, OQ-010, OQ-011, and OQ-018 are mapped without status change |

The eight themes were consolidated into seven questions before identifier
allocation. Protected-evidence treatment remains within admissibility;
evidence-chain preservation remains within custody and responsibility. No
allocated RQ was rejected, withdrawn, or superseded.
