## 2. Scope, Intended Use, and Exclusions

This pack provides registered evidence for the seven admitted D2 Review
Questions. It contains governing evidence controls, operated D1 examples,
historical evidence-loss context, role controls, validation records, and
traceability evidence.

It may support later evidence examination only after a separate session-entry
gate. It does not:

- answer an RQ or state what evidence substantively proves;
- create a Governance Finding, Founder Decision, Constitutional Candidate, or
  Deferred Matter;
- resolve an Open Question;
- establish external legal, privacy, security, professional, or project policy;
- import D1 findings or decisions as D2 conclusions;
- open a session, amend FEF-RGS-000, approve FEF-P1-002, or authorise
  Engineering Discovery.
