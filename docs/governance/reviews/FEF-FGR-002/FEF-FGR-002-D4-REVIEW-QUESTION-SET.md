## 1. Set Boundary and Admission Basis

This set converts the seven Founder-accepted temporary D4 candidates into
canonical Review Questions. Every Question Text field reproduces the
corresponding validated candidate wording exactly.

The validated candidate fields supply the title, purpose, boundaries,
dependencies, Open Question interface, cross-domain interface, and generic
intended evidence domain. No evidence requirement is derived at this gate.
No source is identified or registered, and no evidence conclusion or
substantive answer is introduced.
