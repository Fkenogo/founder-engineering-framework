## 1. Set Boundary and Admission Basis

This set converts the six Founder-Confirmed-with-Amendment temporary D6
candidates into canonical Review Questions. Every Question Text field
below reproduces the finalised wording exactly: the Founder's own
replacement text for D6-RQC-01 and D6-RQC-06 (recorded verbatim in
FEF-FGR-002-D6-RQC-FDR-001 §2), and the FEF-FGR-002-D6-AP-001-drafted
wording for D6-RQC-02 through D6-RQC-05, itself independently demonstrated
strictly within each Founder amendment instruction and validated Pass in
FEF-FGR-002-D6-APVR-001.

The validated candidate fields in FEF-FGR-002-D6-RQC-001 supply the
purpose, scope, exclusions, dependencies, Open Question interface, and
generic intended evidence domain for each Question, refined only where a
Founder amendment instruction or the resulting FEF-FGR-002-D6-AP-001
drafting required it. No evidence requirement is derived at this gate. No
source is identified or registered, and no evidence conclusion or
substantive answer is introduced.
