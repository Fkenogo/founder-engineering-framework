## Purpose

The Founder Engineering Framework is a governed methodology for conceiving, defining, governing, engineering, validating, deploying, reviewing, and preserving software products developed through collaboration between founders, technical leaders, engineers, and AI systems.

FEF is intended to reduce repeated project-setup work while preserving explicit Founder authority, evidence-based engineering, controlled deviations, implementation traceability, and institutional knowledge.

## Current Boundary

This repository does not yet contain an approved framework release.

No project may claim formal adoption of FEF until:

1. the Framework Constitution is approved;
2. the authority and document hierarchy are approved;
3. the adoption and deviation standards are approved;
4. the minimum core framework documents are approved;
5. an official FEF version is released.

Existing project methods remain authoritative within their respective projects until replaced or incorporated through governed adoption.
